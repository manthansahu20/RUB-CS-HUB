📖 About

RUB-CS-HUB is a student-driven Computer Science resource repository created for students of Rajendra University.

It brings together programming codes, study notes, SQL queries, practical resources, and Previous Year Question Papers (PYQs) in one organized place.

The goal is simple:

«🎯 Make Computer Science learning easier, more organized, and accessible to every RUB student.»

Whether you are preparing for practicals, assignments, internal examinations, semester examinations, or learning programming from scratch, RUB-CS-HUB is designed to help.

🤝 Contributing

RUB-CS-HUB is built for RUB students, by RUB students.

If you have useful:

- 📚 Notes
- 💻 Programming codes
- 📝 PYQs
- 🗄️ SQL queries
- 📓 Practical resources
- 💡 Corrections or improvements

you are welcome to contribute.

How to contribute

1. Fork the repository
2. Create a new branch
3. Add or improve a resource
4. Follow the existing folder structure
5. Update the relevant README
6. Commit your changes
7. Create a Pull Request

«💡 Every useful contribution helps another student learn faster.»
